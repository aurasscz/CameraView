CameraView

View your RTSP cameras in the browser

Browsers can't open rtsp:// streams directly, so CameraView uses a small local gateway (go2rtc) that converts RTSP into WebRTC / MSE video. Nothing leaves your network.

  1. Start the gateway on a computer on the same network as your cameras: 
    git clone https://github.com/aurasscz/CameraView
cd CameraView
./gateway/start.sh        # macOS / Linux
# or: powershell -ExecutionPolicy Bypass -File gateway\start.ps1
# or: docker compose up -d
  2. Connect — the status pill at the top turns green when the gateway is reachable (default http://localhost:1984; change it in Settings).
  3. Add a camera with its RTSP URL, or press Scan to find ONVIF cameras.
